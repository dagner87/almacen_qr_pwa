# almacen_qr_pwa
Control de inventario
Creación de racks con cinco niveles y varias posiciones por nivel.

Identificadores de ubicación como R01-N02-P03.

Registro de pallets mixtos con marca, descripción y cantidad de cajas.

Generación e impresión de etiquetas QR para ubicaciones y pallets.

Escaneo con cámara, búsqueda manual y traslado de pallets.

Historial de movimientos.

Exportación de inventario a CSV y copias de seguridad JSON.

Almacenamiento local y una opción de sincronización entre dispositivos mediante Supabase.
