Datos y sincronización

Sincronización entre dispositivos

Para compartir los mismos datos entre varios teléfonos, configura un proyecto Supabase. Sin estas credenciales, la aplicación trabaja localmente en este dispositivo.

No conectado a Supabase.

Las credenciales se guardan en este navegador. Usa solo la clave pública anon; nunca pongas una service_role key en una PWA.

Importar y exportar

Haz copias de seguridad o mueve datos manualmente entre dispositivos. La importación reemplaza los datos locales actuales.

Instalar en iPhone

  1. Publica esta carpeta en un hosting HTTPS, por ejemplo GitHub Pages.
  2. Abre la URL en Safari.
  3. Pulsa Compartir → Añadir a pantalla de inicio.
  4. Permite el uso de la cámara al escanear. La cámara requiere HTTPS.

Nota sobre los datos

La versión inicial usa almacenamiento local y sincronización Supabase opcional. Configura Supabase siguiendo el archivo README y el SQL incluido antes de usar varios dispositivos en operaciones reales. Realiza copias de seguridad regularmente.
