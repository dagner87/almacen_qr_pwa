ADMINISTRACIÓN

Administrar almacén

Agregar posiciones a un rack

Se añadirán posiciones al nivel seleccionado. Los usuarios solo pueden usar posiciones existentes.

Estructura y eliminación

Selecciona varios racks, niveles o posiciones. Al eliminarlos, también se eliminarán los pallets guardados en sus posiciones.

Sin elementos seleccionados
Usuarios y roles

Las cuentas se crean en Supabase Authentication. Aquí puedes asignar roles y controlar el acceso a cada módulo. El permiso Pallets permite crear, editar y mover pallets; Movimientos es de consulta.

CONFIGURACIÓN

Configuración

Alertas de stock por correo

Define el mínimo y el máximo de cada producto. Cuando el stock total llegue cerca del mínimo (o por debajo) se envía un correo para solicitar mercancía, máximo una vez cada 24 h por producto.

Mínimos y máximos por producto

Deja ambos campos vacíos para no controlar ese producto. El máximo es opcional y se usa para sugerir cuánto pedir.

Datos y sincronización

Sincronización en tiempo real

Los cambios se comparten al instante entre usuarios conectados. Si se pierde la conexión, el sistema queda en modo de solo consulta hasta recuperar la conexión.

Conectado a Supabase Realtime.

La URL y clave pública de Supabase se configuran en el entorno de Netlify. Nunca uses una clave service_role en la app.

Importar y exportar

Exporta copias JSON sin credenciales. Importar combina racks, posiciones y pallets con los datos en la nube; no borra registros existentes ni reemplaza el historial de auditoría.

Catálogo de productos

Códigos y descripciones (del Excel de Massimo Dutti). Al escribir un código en un pallet, la descripción se completa sola.

Borrar todos los pallets

Elimina todos los pallets (y su contenido) de la base de datos para volver a importar un JSON limpio. Los racks, las posiciones y los usuarios no se tocan. Se recomienda exportar una copia antes.

Instalar en iPhone
  1. Publica esta carpeta en un hosting HTTPS, por ejemplo GitHub Pages.
  2. Abre la URL en Safari.
  3. Pulsa Compartir → Añadir a pantalla de inicio.
  4. Permite el uso de la cámara al escanear. La cámara requiere HTTPS.
Nota sobre los datos

Los cambios requieren una sesión autenticada y una conexión activa con Supabase Realtime. Al perder conexión, los datos sincronizados quedan disponibles en modo de solo consulta; no se guardan cambios locales pendientes. Exporta copias de seguridad regularmente.

Crear estructura de racks

Se crearán racks con 5 niveles y posiciones numeradas por nivel. Los códigos ya existentes no se duplican.

Códigos de barras de ubicaciones

Etiquetas Code 128 para imprimir y pegar en cada posición. El texto conserva el formato R01-N02-P03.

Nuevo pallet

Cada código único corresponde a una caja. Pega un código por línea. Máximo 25 cajas por pallet. Estos códigos quedan en el pallet y no se agregan al catálogo.
