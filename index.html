CONFIGURACIÓN

Datos y sincronización

Sincronización en tiempo real

Los cambios se comparten al instante entre usuarios conectados. Si se pierde la conexión, el sistema queda en modo de solo consulta hasta recuperar la conexión.

Conectado a Supabase Realtime.

La clave pública se guarda en este navegador; nunca uses una clave service_role en la app.

Importar y exportar

Exporta copias JSON sin credenciales. Importar combina racks, posiciones y pallets con los datos en la nube; no borra registros existentes ni reemplaza el historial de auditoría.

Instalar en iPhone

  1. Publica esta carpeta en un hosting HTTPS, por ejemplo GitHub Pages.
  2. Abre la URL en Safari.
  3. Pulsa Compartir → Añadir a pantalla de inicio.
  4. Permite el uso de la cámara al escanear. La cámara requiere HTTPS.

Nota sobre los datos

Los cambios requieren una sesión autenticada y una conexión activa con Supabase Realtime. Al perder conexión, los datos sincronizados quedan disponibles en modo de solo consulta; no se guardan cambios locales pendientes. Exporta copias de seguridad regularmente.
